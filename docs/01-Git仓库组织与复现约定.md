# 01：Git 仓库组织与复现约定

- 日期：2026-11-13，Asia/Shanghai。
- 目标：将工作区整理为可版本管理、便于后续公开的 Git 仓库，同时保留现有本地环境与实验数据。
- [返回索引](README.md)。

## 1. 起始状态与问题

工作区原先没有 Git 仓库；`deep-swe/` 和 `pier/` 各自已经是独立上游仓库，其中 Pier 有一处已保存补丁的本地修改。项目内另有约 1 GB 的工具与依赖环境、生成的任务副本和原始运行日志。

直接提交整个目录会混入运行环境与生成物，也无法清楚表达上游版本和本地改动之间的关系。

## 2. 组织决定

主仓库跟踪以下材料：

- 项目说明、环境参考、助手约定及按编号的研究文档。
- 自有脚本、固定版本清单、ARM 适配补丁。
- 任务文件哈希清单、官方镜像架构元数据。
- 主动导出的精简实验摘要。

主仓库忽略 `.runtime/`、两个上游 checkout、生成的 `arm/tasks/`、原始实验日志、模型、镜像归档与本地凭据文件。忽略不删除已有本地文件。

采用“版本清单 + 恢复脚本 + 补丁”的方式管理上游依赖，不把上游历史或源码复制进主仓库。`config/versions.json` 保存上游 URL/提交、Python 版本、基础镜像摘要、Docker 工具版本与校验值。

## 3. 新增操作入口

| 文件 | 用途 |
| --- | --- |
| [根 README](../README.md) | 项目定位、当前进度、复现与日常 Git 操作 |
| [版本清单](../config/versions.json) | 恢复所需的固定版本 |
| [bootstrap.py](../scripts/bootstrap.py) | 恢复上游源码、应用 Pier 补丁、安装项目内工具与锁定依赖；不启动 Docker 服务或 NPU 推理 |
| [export_public_results.py](../scripts/export_public_results.py) | 从本地汇总导出不含本机路径与堆栈的精简结果 |

| [第三方来源](../THIRD_PARTY.md) | 第三方许可、通知和补丁来源 |

恢复脚本遇到既有上游 HEAD 不符时停止，不重置本地修改；已应用的补丁不重复叠加。生成任务的已有脚本继续拒绝覆盖现存任务副本。

## 4. 验证与证据

本次验证关注仓库和恢复流程，不重复运行昂贵的任务评分或模型推理：

- 核对两个上游实际提交与版本清单，检查 Pier 补丁已应用。
- `python3 scripts/bootstrap.py --check` 确认当前项目工具可用。
- 导出 2026-11-12 的 11 条历史检查，保留其中 10 条符合预期和 1 条权限异常，核对 F2P/P2P 指标没有改变。
- 检查拟提交文件列表、忽略规则、文件大小与明显凭据特征。
- 检查根目录和文档链接；被忽略的本地实验链接在公开克隆中不保证存在，已在 README 中说明。
- 本地初始化 main 分支并保存初始提交；远程仓库尚未指定，未推送。

干净暂存快照验证已通过：借助本机已有 Git 源作为下载镜像，按固定提交恢复两个上游 checkout；连续执行两次源码恢复没有重复应用补丁。随后重新生成全部 113 个 ARM 配置副本，1243 个文件与原工作区逐字节校验一致，准备清单也一致。这验证了仓库材料可重建当前任务副本，但没有重新测试外部 GitHub 网络或重新下载完整运行环境。

本次纳入版本管理的文件约 260 KiB，未包含两个上游目录、`.runtime/`、任务副本、原始日志或模型权重。明显私钥和常见访问令牌特征检查未发现匹配；该检查不作为所有敏感信息均已识别的保证。

## 5. 使用约定与下一步

研究完成一个明确阶段后，提交对应脚本、配置、摘要及文档。实验环境变化同时更新 ENVIRONMENT.md；历史版本在对应编号文档中保留。后续研究从索引中的下一个编号继续，不能再固定假定 01 是模型部署文档。

公开仓库的名称、远程地址和原创部分许可尚未选择。本次只准备本地版本管理基础，不创建外部仓库或发布项目。模型部署与 KV Cache 学习实验仍未执行。

同步原则：保留原本地历史为 `local-bootstrap-history`，抓取远程发布提交，以一致的文件树和逐文件 blob SHA 核对内容，再让本地 `main` 跟踪 `origin/main`。此过程不强推远程，不删除原本地提交，不改动被忽略的实验环境。

GitHub 连接的写权限不自动配置服务器 Git 凭据。以后通过终端运行 `git push` 仍需完成一次终端认证；当前不向服务器保存访问令牌。
